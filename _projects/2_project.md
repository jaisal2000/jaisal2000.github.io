## Overview

A replication study of the FAHT framework (IJCAI 2019), implementing a custom decision tree induction algorithm with Fair Information Gain (FIG) as a splitting criterion.

### Key Achievements

- **48% Reduction in Discrimination**: Achieved significant reduction in Statistical Parity discrimination on the Adult Census dataset
- **Minimal Accuracy Trade-off**: Maintained accuracy with less than 2% loss
- **Custom Implementation**: Built decision tree induction algorithm from scratch with fairness constraints

### Technologies Used

- Python
- Scikit-Learn
- Fair ML Techniques
- Statistical Analysis
